      Counting

      • Every file in the skill folder counts, including references/, scripts/, templates/ and assets/. Files in a nested skill count toward that skill.
      • Templates: .docx/.xlsx/.pptx, Jinja and other template files, or anything named or filed as a template. Markdown templates are counted as markdown, since your UI accepts them.
      • As published: Anthropic’s document skills are docx 61 files, xlsx 53, pptx 56 (mostly scripts and schemas). Connectors and installed libraries add no files.

      What this does not claim

      • Simple business skills (answers, checklists) are usually fine as markdown; this page is about the complex ones.
      • Some losses could be fixed within the rule by copying the missing markdown (playbooks, sibling skills) into the folder, space permitting.
      • Connectors are a separate requirement from file types.
