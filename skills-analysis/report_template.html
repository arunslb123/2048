Filtering to real knowledge work

Sampling and audit

Counting rules

  • A skill is any folder containing SKILL.md. Files in a nested skill folder count toward that nested skill only.
  • Markdown includes SKILL.md itself, so the minimum is 1.
  • Scripts & code: .py .js .ts .sh .sql .html .css and similar. Data/config: .json .yaml .csv .xml .xsd .txt. Binary assets: images, fonts, audio/video, Office/PDF files.
  • Means are pulled up by a few large folders (e.g. docx ships 39 OOXML .xsd schemas); medians are the better “typical” figure.
  • Only files inside the skill folder count. Plugin-level CLAUDE.md, CONNECTORS.md, commands and agents are excluded.
