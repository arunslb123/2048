The markdown-only rule: where teams diverge from the field

Could markdown alone do the same job?

An agent opened every non-markdown file and the parts of SKILL.md that use it. “No” means the file executes, validates or transforms something that instructions can’t make exact: recalculating a model, checking Word XML against its schema, measuring audio length. The “yes” cases are evaluation rubrics and catalog metadata that nothing reads at run time. The 36 skills were chosen across all four publisher groups and include the largest ones, so the counts show the range of reasons rather than population shares.

What Anthropic and OpenAI actually say

Every quote below was checked word for word against its live source by a separate agent. Neither lab caps file count at anything near 20, and neither requires markdown-only folders. OpenAI does make instruction-only the default.

    Counting rules

    • A skill is any folder containing SKILL.md. Files in a nested skill folder count toward that nested skill only.
    • Markdown includes SKILL.md itself, so the minimum is 1.
    • Scripts & code: .py .js .ts .sh .sql .html .css and similar. Data/config: .json .yaml .csv .xml .xsd .txt. Binary assets: images, fonts, audio/video, Office/PDF files.
    • Means are pulled up by a few large folders (e.g. docx ships 39 OOXML .xsd schemas); medians are the better “typical” figure.
    • Only files inside the skill folder count. Plugin-level CLAUDE.md, CONNECTORS.md, commands and agents are excluded.
